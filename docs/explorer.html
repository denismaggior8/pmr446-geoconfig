📖 Protocol Math Context

The primary configuration is computed via the 2D modular shift grid (17Y + X) mod 304.

Adjacent cells within the nominal radio range (shaded grey on map) are evaluated. Their primaries are sorted by Haversine distance ascending and loaded into the set up to capacity K.

This guarantees that any two overlapping cells share at least one common standby config, while avoiding global transitive lock-in!
